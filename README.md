# GetPractical Azure Container Apps Sandboxes lab

A reproducible PowerShell, Bicep, and Python lab for Azure Container Apps
Sandboxes: deployment, memory and disk state, egress policies, persistent
storage, and measured startup.

The first downloadable release is being prepared. The lab will be available
here under the MIT license, with setup instructions and versioned ZIP downloads.

This is an independent educational lab, not an official Microsoft product.
